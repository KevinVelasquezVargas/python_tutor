# Guía de Atajos de Teclado - Control de Foco y Asistencia Activa

Esta guía te permitirá navegar y utilizar el entorno de aprendizaje de manera eficiente mediante atajos de teclado.

## Atajos de inicio del complemento

* NVDA + Control + Shift + P
  Inicia el complemento y activa la interfaz de aprendizaje.

## Navegación rápida entre paneles principales

Presiona Control junto con los números de la fila superior de teclas para mover el foco directamente al panel deseado:

* Control + 1
  Selector de temario: Elige el tema o capítulo.
* Control + 2
  Panel de teoría: Contenido explicativo del tema.
* Control + 3
  Instrucciones de la práctica: Enunciado del ejercicio.
* Control + 4
  Editor de texto: Espacio para escribir o pegar código.
* Control + 5
  Consola de resultados: Muestra la salida del código ejecutado.
* Control + 6
  Lector de la última línea: Anuncia la última línea de la consola.

## Atajos de asistencia activa (dentro del editor/práctica)

* Control + E
  Ejecutar y analizar el código actual del editor.
* Control + R
  Reiniciar el ejercicio: Vuelve al estado original del capítulo.
* Control + L
  Limpiar la consola: Borra todo el contenido mostrado.
* Control + G
  Abrir buscador del Glosario Interactivo: Consulta términos clave.
* Control + T
  Cargar plantilla: Inserta un código estructural para el tema actual.
* Control + D
  Consultar comando: Explica el significado del comando bajo el cursor usando el glosario.
* Control + H
  Historial de consola: Alterna entre el resultado actual y el anterior.

## Notas de teclado para el editor de texto

* Escape (Esc)
  Sale del editor y enfoca la consola de resultados.
* Tabulador
  Inserta 4 espacios fijos (no una tabulación) para mantener el sangrado correcto según el estándar PEP 8 (Python).

## Acerca de este Complemento

### ¿Qué es?
Este complemento para NVDA (NonVisual Desktop Access) está diseñado para facilitar el aprendizaje del lenguaje de programación Python a personas con discapacidad visual. Actúa como una interfaz de navegación y control rápida, permitiendo al estudiante o desarrollador moverse entre los paneles esenciales de un entorno de enseñanza (temario, teoría, instrucciones, editor de código y consola de resultados) y ejecutar acciones clave sin necesidad de usar el ratón ni recorrer la interfaz visual con el cursor.
