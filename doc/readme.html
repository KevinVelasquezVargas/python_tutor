1. Introducción y Filosofía Didáctica

Aprendizaje de Python con NVDA es un entorno diseñado para eliminar de raíz las barreras habituales a las que se enfrentan las personas ciegas o con baja visión al aprender programación.

El diseño pedagógico se rige por el principio de «Conceptos Primero» y la no sobrecarga cognitiva:

  • Fundamentación conceptual previa: Antes de escribir código formal, se afianzan los conceptos abstractos (algoritmos cotidianos, memoria, decisiones, colecciones y objetos) mediante analogías del mundo real.
  • Micro-pasos de aprendizaje: Cada capítulo se divide en 4 fases metodológicas: concepto guiado, análisis reflexivo de código, misión práctica interactiva y verificación conceptual mediante preguntas breves.
  • Cero trampas visuales: Se evitan ejercicios complejos de reordenar código desordenado o contar caracteres visualmente.

Misión: Proporcionar un puente sólido desde los primeros pasos lógicos hasta el desarrollo de software profesional con bases de datos, librerías estándar y pruebas unitarias.

2. Compatibilidad y Requisitos del Sistema

  • Lector de pantalla: NVDA versión 2022.1.0 hasta la versión 2026.3.0 oficial (ambas inclusive).
  • Sistema Operativo: Microsoft Windows 10, Windows 11 o superior (arquitecturas x86, x64 y ARM64).
  • Intérprete de Python: Utiliza el entorno de ejecución Python integrado en NVDA. No requiere instalar Python por separado ni configurar variables de entorno en Windows.

3. Primeros Pasos e Inicio Rápido

Para abrir el entorno en cualquier momento dispone de las siguientes vías:

  1. Atajo global de teclado: Pulse NVDA + Control + Shift + P.
  2. Menú Herramientas de NVDA: Abra el menú de NVDA con NVDA + N, acceda a Herramientas > Aprendizaje de Python con NVDA > Aprendizaje de Python con NVDA....

Al abrir la ventana, el foco se sitúa de forma automática en el Editor de código. En cualquier momento puede cerrar la ventana de manera instantánea presionando la tecla Escape.

4. Dualidad de Uso: Modo Aprendizaje y Modo Solo Editor

El complemento incorpora dos modos de trabajo perfectamente integrados que se pueden conmutar en cualquier momento pulsando Control + M o desde el menú Herramientas / Configuración:

Modo Aprendizaje (Didáctico):
Presenta el currículo guiado con la barra de estado del capítulo, la caja de lectura de misiones, los botones de pistas escalonadas, explicación de línea y navegación de pasos. Al pulsar Control + Enter, el tutor evalúa los requisitos formativos del ejercicio.
Modo Solo Editor (Profesional):
Transforma la interfaz en un editor de código limpio y libre de distracciones. Oculta las cajas de instrucciones y botones pedagógicos, maximizando el espacio de pantalla para el buffer de edición y la consola de salida. Permite escribir, depurar y ejecutar scripts de Python propios sin validaciones de ejercicios. Mantiene al 100% todas las herramientas tiflotécnicas avanzadas.

5. Herramientas Tiflotécnicas de Edición

Navegación Estructural Directa

En ficheros extensos, desplazarse línea a línea resulta ineficiente. El complemento incluye navegación directa por cabeceras:

  • Alt + N: Salta a la cabecera de la siguiente función (def) o clase (class) en el buffer.
  • Alt + P: Salta a la cabecera de la función o clase anterior.
  • Control + Shift + O: Abre la Lista de Funciones y Clases (diálogo de símbolos), enumera todos los bloques con su número de línea y permite saltar directamente al elemento seleccionado al pulsar Enter.

Salto Inmediato a la Línea del Error (F4)

Cuando una ejecución produce un error de sintaxis o una excepción con Traceback, pulsar F4 posiciona el cursor inmediatamente en la línea exacta del fallo dentro del editor y verbaliza el diagnóstico técnico por voz y braille.

Verificador de Delimitadores y Comillas (F7)

Pulsar F7 analiza el código sin ejecutarlo. Comprueba minuciosamente el balanceo de delimitadores: paréntesis (), corchetes [], llaves {} y comillas simples o dobles sin cerrar. Si detecta una discordancia, sitúa el cursor en la línea del problema e indica el elemento esperado.

Lectura de Consola sin Perder Foco

Para mantener la máxima agilidad mientras programa en el editor:

  • Control + Shift + C: Verbaliza todo el texto de la consola de resultados sin retirar el cursor del editor de código.
  • Control + 6: Lee únicamente la última línea emitida en la consola.
  • F6: Alterna el foco físico entre el editor de código y la consola de salida.

Traductor a Lenguaje Humano (F1)

Al pulsar F1 sobre cualquier línea de código, el tutor analiza su estructura y la traduce a explicaciones en español coloquial. Por ejemplo:

  • def calcular_total(precio, iva): → "Definición de función: Declara la función 'calcular_total' que recibe los parámetros 'precio' e 'iva'."
  • class Vehiculo: → "Declaración de clase: Define la plantilla u objeto 'Vehiculo'."
  • with open('datos.txt', 'r') as f: → "Apertura segura de archivo: Abre 'datos.txt' en modo lectura con cierre automático garantizado."

Linter Acústico de Sangría PEP 8

Emite tonos auditivos diferenciados en tiempo real según el nivel de indentación de la línea activa:

  • 0 espacios: Clic sutil de alineación raíz.
  • 4 espacios: Tono agudo claro (primer nivel de bloque).
  • 8 espacios: Tono armónico medio (segundo nivel).
  • 12 o más espacios: Tono armónico agudo (tercer nivel anidado).
  • Dos puntos (:): Tono ascendente de apertura de bloque.

Laboratorio de Pruebas Rápidas (REPL - Control + J)

Ventana emergente para ensayar cálculos, llamadas a métodos o expresiones puntuales de Python sin modificar el código del editor principal.

Diccionario de Términos (Control + G)

Buscador interactivo con 43 definiciones técnicas accesibles que abarcan desde conceptos elementales (variable, algoritmo, print) hasta paradigmas avanzados (herencia, JSON, SQLite, unittest, recursividad).

7. Plan Formativo Integral (32 Capítulos / 128 Micro-pasos)

El currículo abarca desde la formulación lógica previa hasta el desarrollo de aplicaciones completas, dividido en 6 fases pedagógicas:

Fase 0: Pensamiento Computacional y Fundamentos Conceptuales

  1. Capítulo 1: Pensamiento Computacional y Algoritmos Cotidianos: Instrucciones paso a paso, secuencia ordenada y analogías de la vida real.
  2. Capítulo 2: Cómo Piensa una Computadora: Memoria, Procesador y Secuencia: El ciclo de instrucción, almacenamiento de datos y flujo lineal.
  3. Capítulo 3: Lógica Booleana Elemental: Verdadero, Falso y Decisiones: Estados lógicos, condiciones binarias y compuertas lógicas (AND, OR, NOT).

Fase 1: Sintaxis Básica y Tipos Elementales

  1. Capítulo 4: Tu Primer Programa: Salida con print y Textos Entrecomillados: Emisión de mensajes accesibles por voz y braille.
  2. Capítulo 5: Variables: Contenedores de Información en Memoria: Creación, asignación con = y reutilización de valores.
  3. Capítulo 6: Tipos de Datos Primitivos: Números Enteros y Decimales: Operaciones aritméticas con int y float.
  4. Capítulo 7: Cadenas de Texto (str) y Operaciones Básicas: Concatenación, repetición y formateo claro.
  5. Capítulo 8: Entrada de Datos del Usuario: input y Conversión de Tipos: Recepción interactiva de datos y conversión con int() / float().

Fase 2: Estructuras de Control y Colecciones Fundamentales

  1. Capítulo 9: Comparaciones y Condiciones: Mayor, Menor e Igualdad: Operadores relacionales (>, <, ==, !=).
  2. Capítulo 10: La Estructura Condicional if y la Importancia de la Sangría: Bloques subordinados a 4 espacios y sangría PEP 8.
  3. Capítulo 11: Caminos Alternativos: if, elif y else: Evaluación de múltiples ramas condicionales.
  4. Capítulo 12: Colecciones Ordenadas: Introducción a las Listas: Declaración entre corchetes [] e indexación base 0.
  5. Capítulo 13: Modificando Listas: append, remove y len: Métodos mutables e inspección de tamaño.
  6. Capítulo 14: Bucles y Automatización: Recorridos con for y range: Iteración predeterminada sobre listas y rangos numéricos.
  7. Capítulo 15: Bucles Mientras: Repetición Condicionada con while: Ciclos condicionados, contadores y prevención de bucles infinitos.
  8. Capítulo 16: Estructuras Clave-Valor: Diccionarios en Python: Almacenamiento asociativo mediante llaves {}.

Fase 3: Modularidad, Robustez y Persistencia Básica

  1. Capítulo 17: Colecciones Inmutables y Conjuntos: Tuplas y Sets: Integridad de datos con tuple y unicidad con set.
  2. Capítulo 18: Modularidad: Creando Nuestras Propias Funciones con def: Reutilización de código y paso de argumentos.
  3. Capítulo 19: Retorno de Valores y Ámbito de Variables (Scope): La sentencia return, variables locales y globales.
  4. Capítulo 20: Programas Robustos: Control de Excepciones con try y except: Prevención de bloqueos ante datos inesperados.
  5. Capítulo 21: Depuración y Análisis de Errores: Cómo Leer un Traceback: Comprensión no visual del rastro de errores y uso de F4.
  6. Capítulo 22: Manejo Seguro de Ficheros: Lectura y Escritura con with open: Persistencia en disco con cierre garantizado de recursos.

Fase 4: Programación Orientada a Objetos (POO) Accesible

  1. Capítulo 23: Introducción a la Orientación a Objetos: Clases y Atributos: Modelado del mundo real mediante plantillas e instancias.
  2. Capítulo 24: El Constructor __init__ y el Parámetro self: Inicialización de estado y vinculación de instancia.
  3. Capítulo 25: Métodos de Instancia: Acciones que Pertenecen a un Objeto: Comportamientos definidos dentro de la clase.
  4. Capítulo 26: Herencia: Reutilización y Extensión con super(): Clases base y derivadas para modelar jerarquías.
  5. Capítulo 27: Representación Textual Accesible de Objetos con __str__: Generación de cadenas legibles para el sintetizador de voz.

Fase 5: Desarrollo Profesional, Librerías, APIs y Pruebas

  1. Capítulo 28: Librerías de la Biblioteca Estándar: math, random y datetime: Importación y uso de módulos utilitarios.
  2. Capítulo 29: Intercambio de Datos Estructurados con JSON: Serialización y deserialización de cadenas JSON con json.loads() y json.dumps().
  3. Capítulo 30: Bases de Datos Relacionales Ligeras con SQLite3: Creación de tablas, inserción (INSERT) y consulta (SELECT) con SQL nativo.
  4. Capítulo 31: Consumo de Servicios Web y APIs REST: Conexión por red, peticiones GET y consumo estructurado.
  5. Capítulo 32: Calidad de Software: Pruebas Unitarias con unittest: Aserciones automatizadas (assertEqual, assertTrue) para verificar código.

8. Configuración en Opciones de NVDA

El complemento incluye un panel de opciones en el menú estándar de preferencias de NVDA (NVDA + Control + G, categoría Aprendizaje de Python con NVDA). Desde allí puede configurar:

  • Iniciar directamente en Modo Solo Editor profesional: Omite las secciones didácticas al abrir el tutor.
  • Activar señales sonoras y efectos auditivos: Controla los sonidos de inicio, pasos superados y pistas.
  • Activar linter acústico de sangría PEP 8 y sintaxis: Tonos indicadores de nivel de tabulación.
  • Mostrar diálogo de bienvenida al iniciar: Asistente inicial de bienvenida.
