## 1. Introducción
**Aprendizaje de Python con NVDA** es un complemento interactivo diseñado para que personas con discapacidad visual aprendan a programar en Python de manera autónoma, práctica y sin barreras.

A través de una metodología *Action-First* (aprender haciendo), cada paso presenta un concepto claro, un fragmento de código editable y un desafío con retroalimentación inmediata, tanto en voz como mediante señales auditivas.

## 2. Iniciar el complemento
- **Atajo global:** `NVDA + Control + Shift + P`
- **Menú de NVDA:** Menú NVDA > *Herramientas* > *Aprendizaje de Python con NVDA* > *Aprendizaje de Python con NVDA...*

## 3. Atajos de teclado principales
* `Control + Enter` (o `Control + E`): Ejecutar código y evaluar la solución.
* `Control + Flecha Derecha`: Avanzar al siguiente paso.
* `Control + Flecha Izquierda`: Retroceder al paso anterior.
* `Control + P`: Pedir una pista escalonada.
* `F1` (o `Control + H`): **Traductor a Lenguaje Humano** (explica la línea actual en español claro).
* `F2`: Ver lista de atajos de teclado.
* `Control + J`: Abrir el Laboratorio Rápido (REPL).
* `Control + G`: Consultar el Glosario de términos y funciones.
* `Control + 1`: Selector de Capítulos.
* `Control + R`: Reiniciar el código del ejercicio actual.
* `Control + O` / `Control + S`: Abrir y guardar archivos Python (.py).
* `Escape`: Cerrar la ventana del complemento.

## 4. Opciones y Configuración
Las opciones del complemento se encuentran en el menú de Preferencias de NVDA:
`Menú NVDA > Preferencias > Opciones > Aprendizaje de Python con NVDA`
* Activar o desactivar efectos sonoros.
* Activar o desactivar el linter acústico de sangría PEP 8.
* Mostrar u ocultar el diálogo de bienvenida al iniciar.
