1. Introducción y Filosofía

Aprendizaje de Python con NVDA es un complemento diseñado específicamente para facilitar la enseñanza y el aprendizaje del lenguaje de programación Python a personas usuarias de lectores de pantalla.

El complemento adopta una pedagogía activa (Action-First): en lugar de obligar al estudiante a memorizar extensos párrafos teóricos antes de poder interactuar, cada lección comienza en el editor de código con un concepto puntual, un ejemplo funcional y un reto práctico verificable al instante.

Objetivo: Que cualquier persona, incluso sin experiencia previa en informática, pueda escribir su primer programa, comprender la lógica computacional y dominar Python con total autonomía y accesibilidad.

2. Compatibilidad y Requisitos

  • Lector de pantalla: NVDA versión 2022.1.0 hasta la versión 2026.3.0.
  • Sistema Operativo: Microsoft Windows 10, Windows 11 o superior (32 y 64 bits).
  • Entorno de ejecución: Utiliza el intérprete de Python integrado nativamente en NVDA, sin requerir instalaciones externas ni configuraciones de variables de entorno.

3. Primeros Pasos e Inicio

Para abrir el complemento en cualquier momento dispone de dos métodos:

  1. Gesto global de teclado: Pulse NVDA + Control + Shift + P.
  2. Menú de NVDA: Abra el menú de NVDA con NVDA + N, desplácese a Herramientas, entre en el submenú Aprendizaje de Python con NVDA y seleccione Aprendizaje de Python con NVDA....

Al iniciarse por primera vez, el complemento le presentará un diálogo de bienvenida con instrucciones claras y un resumen de las teclas indispensables. El cursor se posicionará de forma inmediata en el Editor de código para que pueda comenzar a escribir sin rodeos.

4. Integración en el Menú de NVDA

En el menú Herramientas de NVDA encontrará el submenú Aprendizaje de Python con NVDA con tres accesos directos:

  • Aprendizaje de Python con NVDA...: Abre la ventana principal del entorno de aprendizaje.
  • Soporte y contacto...: Abre un enlace de correo directo para plantear dudas, sugerencias o reportar incidencias.
  • Realizar una donación...: Abre la página de contribución voluntaria para apoyar el desarrollo continuo y gratuito del complemento.

6. Características Principales

Traductor a Lenguaje Humano (F1 / Control + H)

Una de las herramientas más innovadoras del complemento. Cuando esté situado sobre cualquier línea de código en el editor y presione F1 o Control + H, el tutor descompondrá sintácticamente esa línea y se la explicará en lenguaje natural cotidiano.

Por ejemplo:

  • print('Hola') se traduce como: "Instrucción de salida (print): Muestra en pantalla y lee con el sintetizador el texto 'Hola'."
  • edad = 25 se traduce como: "Asignación de variable: Guarda en la variable 'edad' el número entero 25."
  • if edad >= 18: se traduce como: "Condicional 'si': Comprueba si el valor de 'edad' es mayor o igual a 18. Si se cumple, ejecutará las instrucciones indentadas siguientes."
  • for item in lista: se traduce como: "Bucle 'para cada' (for): Recorrerá uno a uno los elementos de 'lista', asignando cada uno a la variable temporal 'item'."

Linter Acústico de Sangría PEP 8

En Python, la sangría (los espacios en blanco al inicio de una línea) define qué bloques de código pertenecen a funciones, bucles o condicionales. Para evitar que el usuario tenga que contar espacios manualmente con el cursor, el complemento emite señales auditivas diferenciadas según el nivel de indentación:

  • 0 espacios (nivel raíz): Clic sutil de alineación izquierda.
  • 4 espacios (primer nivel de bloque): Tono agudo limpio (880 Hz).
  • 8 espacios (segundo nivel anidado): Tono armónico superior (1100 Hz).
  • 12 espacios (tercer nivel anidado): Tono agudo brillante (1320 Hz).
  • Dos puntos (:) al declarar un bloque: Tono de barrido ascendente confirmando la apertura de bloque.
  • Olvido de dos puntos al presionar Enter en una estructura: Señal acústica preventiva descendente.

Laboratorio Rápido (REPL) (Control + J)

Permite evaluar expresiones de una sola línea al vuelo. Puede probar operaciones matemáticas, comprobar qué tipo de dato devuelve una función o experimentar con métodos de texto sin alterar el ejercicio principal.

Glosario de Términos (Control + G)

Un diccionario técnico accesible con buscador instantáneo en tiempo real. Permite consultar el significado, uso y ejemplos de palabras clave como int, str, def, return, list, append, lambda y más.

Configuración en Preferencias de NVDA

Para mantener la ventana principal despejada y libre de sobrecarga, las opciones de configuración se encuentran integradas en el panel nativo de preferencias de NVDA (NVDA + Control + G, categoría Aprendizaje de Python con NVDA). Desde allí puede activar o desactivar:

  • Efectos sonoros y señales auditivas.
  • Linter acústico de sangría y avisos de sintaxis.
  • Mostrar el diálogo de bienvenida al iniciar.

7. Estructura del Temario de Aprendizaje

El plan de estudios está organizado en 15 capítulos progresivos, diseñados de menor a mayor complejidad:

  1. Capítulo 1: Conceptos Básicos y Primer Saludo: ¿Qué es programar y qué es Python? Tu primer print('Hola mundo'), comillas y orden secuencial.
  2. Capítulo 2: Texto, Mensajes y Números en la Salida: Operaciones matemáticas dentro de print, concatenación con comas y detección de errores de escritura (NameError).
  3. Capítulo 3: Almacenamiento en Memoria y Variables: El operador de asignación (=), reutilización y actualización de variables.
  4. Capítulo 4: Tipos de Datos Primitivos (str, int, float): Diferencias entre cadenas de texto, enteros y números con decimales.
  5. Capítulo 5: Estructuración y Sangría PEP 8: Importancia de los 4 espacios, la tecla Tabulador y bloques subordinados.
  6. Capítulo 6: Conversión de Tipos (Type Casting): Uso de int(), float() y str() para transformar datos.
  7. Capítulo 7: Prioridad de Operadores Aritméticos: Precedencia matemática, multiplicación, división entera (//) y módulo (%).
  8. Capítulo 8: Operadores de Comparación y Estructura if: Toma de decisiones mediante >, <, ==, !=.
  9. Capítulo 9: Operadores Lógicos (and, or, not): Combinación de múltiples condiciones en una sola expresión lógica.
  10. Capítulo 10: Decisiones Múltiples con la Cláusula elif: Encadenamiento de alternativas y caso por defecto con else.
  11. Capítulo 11: Secuencias Ordenadas: Introducción a las Listas: Creación de listas, acceso por índice base 0 e índices negativos.
  12. Capítulo 12: Métodos de Listas y Mutabilidad: Modificar listas con append(), remove(), pop() y medir con len().
  13. Capítulo 13: Automatización mediante el Ciclo for: Recorrer listas y secuencias numéricas generadas con range().
  14. Capítulo 14: Funciones y Retorno de Valores: Modularización del código con def, parámetros y la sentencia return.
  15. Capítulo 15: Manejo y Mitigación de Errores con try y except: Construcción de programas robustos capaces de recuperarse de fallos sin cerrarse.

  • Generación de audio síncrona optimizada: Las señales acústicas se generan instantáneamente al iniciar el complemento, garantizando la reproducción inmediata del tono de apertura.
